# UI・レイアウト設計ガイドライン（永続ルール）

## 最重要ルール：不自然な改行・文字切れの絶対禁止

1. **ボタン・スイッチ・ラベルの文言と折り返し**:
   - 日本語のラベルやトグルスイッチは、文や単語の途中で改行させないこと。
   - `white-space: nowrap;`、`word-break: keep-all;`、`line-break: strict;` を適切に適用すること。
   - パネルの横幅（約300px）を考慮し、無駄に冗長な文言を避け、自然で洗練された簡潔な表現にすること。

2. **オーバーレイ要素のサイズ設計**:
   - 最大文字数（例:「エンタメ・カルチャー」「IT・テクノロジー」）が入っても、末尾が `...` に切り詰められたり枠からはみ出たりしない幅（例: 225px以上）を最初から確保すること。

3. **配信画面の視認性（スクロールバーの排除）**:
   - 自動配信・定時配信の画面では誰も手動スクロールを行わないため、すべての要素（10カテゴリなど）が1画面内にすっきり収まるコンパクトなレイアウト設計にすること。
   - スクロールバーは `scrollbar-width: none;` で完全非表示にすること。
